## Профессиональный опыт

Практический опыт разработки программного обеспечения — **около 2,5 лет**, из них **примерно шесть месяцев работы с технологиями искусственного интеллекта**.

Имеется опыт проектирования баз данных, программирования на Python и PHP, веб-разработки с использованием HTML, CSS и JavaScript, работы с SQL и MySQL.

Python, PHP, HTML и MySQL применялись в реальной разработке, а не только при изучении теоретических материалов.

Опыт работы с AI-технологиями включает создание работающих прототипов, учебных и портфолио-проектов, интеграцию языковых моделей, разработку RAG-систем, автоматизацию, тестирование и эксперименты с дообучением моделей.

Часть решений реализована в рамках учебных задач, но доведена до работоспособного состояния и протестирована. Наличие работающего прототипа не означает, что он внедрён в коммерческую эксплуатацию.

AI-разработка стала продолжением опыта программирования, проектирования баз данных и создания прикладных программных решений.

## Основные компетенции

### AI-ассистенты и RAG-системы

Разработка AI-ассистентов, использующих собственные базы знаний, семантический поиск и генерацию ответов на основе найденных документов.

Практические направления работы:

- подготовка и структурирование документов для базы знаний;
- разбиение документов на фрагменты (chunking);
- создание векторных представлений (embeddings);
- индексация и семантический поиск;
- использование метаданных и фильтрации результатов;
- применение подходов к повторному ранжированию (reranking);
- управление контекстом языковой модели;
- снижение количества недостоверных ответов;
- интеграция RAG с API и пользовательскими интерфейсами;
- кэширование, журналирование и анализ запросов;
- тестирование и оценка качества поиска и генерации.

Знаком с различными подходами к хранению векторов и организации поиска, включая ChromaDB, Pinecone, Weaviate, FAISS и pgvector.

### Чат-боты и автоматизация

Разработка чат-ботов и автоматизированных сценариев обработки запросов.

Работа с Telegram, ВКонтакте, Telegram Bot API, aiogram, python-telegram-bot, n8n, Albato, Make и Zapier.

Практические задачи:

- получение и обработка сообщений пользователей;
- интеграция чат-ботов с языковыми моделями;
- организация диалоговых сценариев;
- взаимодействие с внешними API;
- использование Webhooks;
- чтение и запись данных;
- обработка ошибок;
- маршрутизация запросов;
- автоматизация повторяющихся операций.

### Программирование и базы данных

Практический опыт разработки с использованием Python, PHP, HTML, CSS, JavaScript и SQL.

Работа с MySQL, PostgreSQL, SQLite и Supabase.

Компетенции включают:

- проектирование структур реляционных баз данных;
- создание и изменение таблиц;
- подготовку SQL-запросов;
- организацию хранения прикладных данных;
- разработку серверной логики;
- обработку JSON и CSV;
- интеграцию приложений с базами данных;
- создание и использование REST API.

Для серверной разработки и API применяются FastAPI, Flask и Pydantic.

### Prompt Engineering

Разработка системных промптов и инструкций для языковых моделей.

Основные направления:

- определение роли и задач AI-ассистента;
- описание допустимого и недопустимого поведения;
- ограничение ответов доступными данными;
- управление контекстом;
- построение многошаговых сценариев;
- извлечение структурированных данных;
- применение JSON Schema и structured output;
- использование function calling и tool calling;
- создание тестовых сценариев;
- сравнение версий промптов;
- анализ ошибок и галлюцинаций.

Имеется практический опыт A/B-тестирования промптов с оценкой релевантности и достоверности ответов.

### Языковые модели и машинное обучение

Работа с облачными и локальными языковыми моделями.

Используемые инструменты и технологии:

- OpenAI API;
- Hugging Face;
- Ollama;
- PyTorch;
- Transformers;
- PEFT;
- LoRA и QLoRA;
- Hugging Face Datasets.

Опыт включает запуск и интеграцию моделей, подготовку наборов данных, эксперименты с параметроэффективным дообучением, тестирование и сравнение результатов.

В проекте Client Request Normalizer выполнен эксперимент по LoRA-дообучению модели Qwen2.5-0.5B-Instruct для преобразования клиентских запросов в структурированный JSON.

### Тестирование и оценка качества

Практическая работа с тестированием программных компонентов, API, AI-ассистентов и языковых моделей.

Используемые инструменты и подходы:

- pytest;
- unittest;
- Postman;
- RAGAS;
- A/B-тестирование;
- функциональное и сценарное тестирование;

- контроль галлюцинаций;

При тестировании AI-систем учитываются как функциональная корректность, так и качество содержательных ответов.

### Развёртывание и сопровождение

## Проекты портфолио

### RAG Assistant

AI-ассистент с поиском по базе знаний, FastAPI, ChromaDB, SQLite-кэшированием и журналированием запросов.

Реализованы обработка запросов, поиск релевантных документов, генерация ответов, кэширование и API-интерфейс.

Демонстрационный API развёрнут на Railway.

Дополнительные возможности для работы с несколькими независимыми базами знаний разрабатываются отдельно от текущей развёрнутой версии.

**Страница проекта:** https://glazounov-ai.ru/portfolio/rag-assistant/

**Подробности:** `rag-assistant.md`.

### AI IT Service Desk

Прототип интеллектуального ассистента для корпоративной технической поддержки.

Использует базу знаний, диагностические сценарии, правила маршрутизации и эскалации.

Поддерживает подготовку структурированного черновика заявки для передачи специалистам технической поддержки.

Не создаёт реальные заявки во внешней Service Desk-системе.

**Страница проекта:** https://glazounov-ai.ru/portfolio/ai-it-service-desk/

**Подробности:** `ai-it-service-desk.md`.

### AI Interview Coach

Ассистент для подготовки кандидатов к собеседованиям.

Поддерживает анализ вакансий, тренировочные вопросы, моделирование интервью, метод STAR и обратную связь.

Реализован как демонстрационный прототип в OpenAI Playground с использованием базы знаний.

**Страница проекта:** https://glazounov-ai.ru/portfolio/interview-assistant/

**Подробности:** `interview-assistant.md`.

### Client Request Normalizer

Эксперимент по LoRA-дообучению компактной языковой модели Qwen2.5-0.5B-Instruct.

Задача модели — преобразование русскоязычных клиентских запросов в структурированный JSON для последующей автоматизированной обработки.

На тестовом наборе из 15 запросов улучшены показатели определения намерения, извлечения полей и соблюдения формата ответа.

Проект является экспериментальной разработкой, а не готовой CRM или производственной системой.

**Страница проекта:** https://glazounov-ai.ru/portfolio/client-request-normalizer/

**Подробности:** `client-request-normalizer.md`.

### A/B Prompt Test

Эксперимент по сравнению двух системных промптов AI-ассистента.

Использовались n8n, GPT-4o mini, Google Sheets и слепая ручная оценка ответов.

На фиксированном наборе из 25 запросов промпт с ограничением домыслов показал более высокую релевантность и меньшую долю галлюцинаций.

Результаты относятся к конкретному тестовому набору и не означают универсального превосходства одного промпта.

**Страница проекта:** https://glazounov-ai.ru/portfolio/ab-prompt-test/

**Подробности:** `ab-prompt-test.md`.

## Подход к разработке

Работа начинается с определения задачи, анализа доступных данных, ограничений и ожидаемого результата.

После этого выбирается архитектура, подготавливаются необходимые компоненты и создаётся работающий прототип.

Следующий этап — проверка на тестовых сценариях, анализ ошибок и последовательная доработка.

Особое внимание уделяется:

- достоверности ответов языковых моделей;
- качеству и актуальности исходных данных;
- проверяемой бизнес-логике;
- корректной обработке ошибок;
- безопасности интеграций;
- тестированию и измерению качества;
- документированию изменений;
- возможности дальнейшего развития системы.

AI рассматривается как компонент программного решения, а не универсальная замена традиционному программированию.

При выборе инструментов учитываются сложность задачи, требования к инфраструктуре, доступные ресурсы и затраты на сопровождение.
