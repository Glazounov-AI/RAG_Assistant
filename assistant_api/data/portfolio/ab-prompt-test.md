# A/B Prompt Test — сравнительное тестирование системных промптов

**Тип проекта:** Prompt Engineering, A/B Testing, AI Evaluation, автоматизация тестирования  
**Статус:** завершённый эксперимент с документированными результатами  
**Модель:** OpenAI GPT-4o mini  
**Технологии:** n8n, OpenAI API, Google Sheets, Microsoft Excel  
**Репозиторий:** https://github.com/Glazounov-AI/ab-prompt-test  
**Страница портфолио:** https://glazounov-ai.ru/portfolio/ab-prompt-test/

## Назначение проекта

A/B Prompt Test — проект для сравнительной оценки качества двух вариантов системного промпта AI-ассистента.

Цель эксперимента — выяснить, помогают ли явные ограничения на использование информации повысить релевантность ответов и уменьшить количество галлюцинаций.

Для автоматизации генерации и сбора ответов использовался n8n. Результаты оценивались вручную в слепом формате.

## Проблема

Базовые инструкции вроде «отвечай вежливо и по существу» не всегда предотвращают появление выдуманных или неподтверждённых сведений.

В клиентских сценариях такие ответы могут вводить пользователя в заблуждение, особенно когда в запросе недостаточно информации.

Проект проверяет, насколько добавление правил о недопустимости домыслов влияет на измеряемое качество ответов.

## Сравниваемые варианты

### Prompt A — базовый

«Ты — консультант компании. Отвечай на вопросы клиентов вежливо, понятно и по существу.»

### Prompt B — с ограничениями

«Ты — консультант компании. Отвечай на вопросы клиентов вежливо, понятно и по существу. Используй только информацию, содержащуюся в запросе клиента. Если для точного ответа информации недостаточно, не придумывай отсутствующие данные, а задай клиенту уточняющий вопрос.»

Оба варианта тестировались на GPT-4o mini.

## Гипотеза

Добавление в системный промпт явных требований не придумывать отсутствующие сведения и задавать уточняющие вопросы улучшит качество ответов по сравнению с базовым вариантом.

**Основная метрика:** Relevance — релевантность ответа.

**Защитная метрика:** Hallucination — наличие выдуманной или неподтверждённой информации.

**Минимально значимый эффект (MDE):** повышение средней релевантности не менее чем на 0,5 балла по пятибалльной шкале.

## Методика эксперимента

Подготовлен фиксированный датасет из 25 запросов, имитирующих клиентские обращения.

Каждый запрос обрабатывался двумя вариантами системного промпта. Таким образом, были получены 25 ответов Prompt A и 25 ответов Prompt B.

Для автоматизации использовался workflow n8n:

1. Чтение запросов из Google Sheets.
2. Генерация ответа с Prompt A.
3. Генерация ответа с Prompt B.
4. Объединение ответов по идентификатору запроса.
5. Случайная перестановка порядка ответов.
6. Сохранение ответов для слепой оценки.
7. Сохранение ключа соответствия ответов вариантам A и B.

Рандомизировался порядок предъявления ответов оценщику, а не распределение реальных пользователей между экспериментальными группами.

После завершения оценки раскрывалось соответствие ответов промптам A и B.

## Метрики качества

### Relevance

Релевантность оценивалась вручную по шкале от 1 до 5:

- 1 — ответ не соответствует запросу.
- 2 — слабо соответствует запросу.
- 3 — частично соответствует запросу.
- 4 — в основном соответствует запросу.
- 5 — полностью соответствует запросу.

Итоговая метрика — средняя оценка релевантности по 25 ответам каждого варианта.

### Hallucination

Бинарная оценка:

- 0 — галлюцинации не обнаружены.
- 1 — обнаружены выдуманные или неподтверждённые сведения.

Итоговая метрика — доля ответов с галлюцинациями.

Оценка проводилась вручную. Это позволяет анализировать содержание ответов, но не исключает субъективности оценщика.

## Результаты

| Метрика | Prompt A | Prompt B | Изменение |
|---|---:|---:|---:|
| Средняя релевантность | 3,08 / 5 | 4,68 / 5 | +1,60 балла |
| Ответы с галлюцинациями | 12 из 25 | 1 из 25 | −11 ответов |
| Доля галлюцинаций | 48% | 4% | −44 процентных пункта |

Фактический прирост релевантности составил 1,60 балла, что превышает установленный MDE в 0,5 балла.

Доля ответов с галлюцинациями снизилась с 48% до 4%.

Таким образом, на использованном наборе Prompt B выполнил оба критерия принятия решения: повысил релевантность не менее чем на 0,5 балла и не ухудшил защитную метрику.

## Принятое решение

По результатам эксперимента Prompt B выбран как предпочтительный вариант для дальнейшего пилотного тестирования.

Это решение относится к конкретному эксперименту на фиксированном наборе запросов.

Оно не означает, что Prompt B гарантированно лучше на любых данных, в других предметных областях или при использовании других языковых моделей.

## Техническая реализация

В проекте использовались:

- **n8n** — автоматизация обработки запросов и сбора ответов.
- **OpenAI GPT-4o mini** — генерация ответов.
- **Google Sheets** — рабочее хранение запросов и результатов.
- **Microsoft Excel** — публикация датасета и оценок.
- **GitHub** — хранение документации и экспортированного workflow.

Основной workflow находится в `workflows/prompt-ab-dataset-test.json`.

Файл `data/datasets.xlsx` содержит тестовые запросы, ответы, оценки и ключ соответствия A/B.

Документация включает `docs/methodology.md` и `docs/results.md`.

Публичный экспорт workflow не содержит привязок к учётным данным автора. Для воспроизведения необходимо настроить собственные подключения OpenAI и Google Sheets.

## Воспроизводимость

Для повторного проведения эксперимента в репозитории представлены:

- экспорт n8n workflow;
- тестовый датасет;
- ответы обоих вариантов;

- описание методики;
- итоговые результаты.

Повторная генерация может дать отличающиеся ответы, поэтому результаты конкретного запуска необходимо фиксировать отдельно.

## Ограничения

1. Использовались 25 тестовых запросов, а не реальный пользовательский трафик.
2. Проверялась одна модель — GPT-4o mini.
3. Оценка качества выполнялась вручную и может быть субъективной.
4. Статистическая значимость различий отдельно не проверялась.
5. Рандомизация касалась порядка ответов при оценке, а не распределения пользователей.
6. Не измерялись конверсия, удовлетворённость пользователей или другие производственные бизнес-метрики.
7. Результаты не гарантируют аналогичного улучшения на других моделях и датасетах.
8. Эксперимент не является подтверждением готовности промпта к промышленному внедрению.

## Практическая ценность

Проект демонстрирует подход к измеримому улучшению AI-ассистентов вместо оценки качества исключительно по субъективному впечатлению.

Он показывает, как можно:

- сформулировать проверяемую гипотезу;
- определить основную и защитную метрики;
- установить минимально значимый эффект;
- автоматизировать получение ответов;
- организовать слепую оценку;
- сопоставить результаты и принять документированное решение.

Такая методика может использоваться при разработке клиентских чат-ботов, корпоративных AI-ассистентов и других решений на основе LLM.

## Краткий ответ для посетителя портфолио

A/B Prompt Test — проект по измеримой оценке качества системных промптов AI-ассистента.

С помощью n8n, OpenAI GPT-4o mini и Google Sheets были протестированы два варианта инструкций на 25 одинаковых клиентских запросах.

Промпт с запретом на домыслы и требованием задавать уточняющие вопросы повысил среднюю релевантность с 3,08 до 4,68 балла и снизил долю ответов с галлюцинациями с 48% до 4%.

Результаты получены в рамках ограниченного офлайн-эксперимента и служат основанием для дальнейшего тестирования, а не гарантией качества в промышленной эксплуатации.
